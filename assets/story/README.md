# Arte de Amelie

Dejá acá tus imágenes (PNG, WebP o SVG) y listalas en `manifest.json`:

```json
{
  "neutral": "amelie-neutral.png",
  "smile": "amelie-smile.png",
  "worried": "amelie-worried.png",
  "glitch": "amelie-glitch.png",
  "dark": "amelie-dark.png"
}
```

- Las expresiones que falten usan `neutral`. Sin `manifest.json` se usa el busto SVG integrado.
- Formato sugerido: busto con fondo transparente, proporción ~120×140 (vertical), mínimo 480×560 px.
